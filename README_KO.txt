CEO 경영 시뮬레이터 — 스마트폰 앱처럼 설치하기
================================================

포함 파일
- index.html : 실제 앱 화면과 게임 로직
- manifest.json : 홈 화면 설치 설정
- sw.js : 오프라인 캐시
- icons/ : 앱 아이콘

중요: 스마트폰의 '홈 화면에 추가' 기능은 보통 HTTPS 주소로 접속해야 사용할 수 있습니다.
HTML 파일을 메신저로 보내서 열면 설치 기능이 제대로 작동하지 않을 수 있습니다.

가장 쉬운 무료 배포 방법 (GitHub Pages)
1. PC에서 https://github.com 에 로그인하거나 계정을 만듭니다.
2. 새 저장소(repository)를 만듭니다. 예: ceo-simulator
3. 이 ZIP을 풀고 안에 들어 있는 파일과 icons 폴더를 저장소의 최상위에 업로드합니다.
   최상위에 index.html, manifest.json, sw.js, icons 폴더가 있어야 합니다.
4. 저장소의 Settings → Pages로 이동합니다.
5. Build and deployment에서 Deploy from a branch를 고르고, Branch는 main, 폴더는 /(root)를 선택한 뒤 Save를 누릅니다.
6. Pages가 제공하는 https://계정이름.github.io/저장소이름/ 주소를 스마트폰에서 엽니다.

안드로이드 (Chrome)
1. 위 주소를 Chrome에서 엽니다.
2. 브라우저 메뉴(⋮)를 누릅니다.
3. '앱 설치' 또는 '홈 화면에 추가'를 선택합니다. 메뉴 이름은 기기마다 다를 수 있습니다.

아이폰 (Safari)
1. Safari에서 위 주소를 엽니다.
2. 공유 버튼을 누릅니다.
3. '홈 화면에 추가'를 선택한 뒤 추가합니다.

사용 방법
- 회사 운영: 매달 광고 마케팅, 제품 개발, 인재 채용, 비용 최적화 중 하나를 선택합니다.
- 실적 보고서: 자금 변화와 경영 기록을 봅니다.
- 목표와 배지: 성공 조건과 획득한 배지를 확인합니다.
- 설정에서 새 회사로 초기화할 수 있습니다.
- 진행 상황은 해당 기기의 브라우저 저장소에 자동 저장됩니다. 브라우저 데이터 삭제 시 저장 기록도 없어질 수 있습니다.
- 한번 캐시가 만들어지면 기본적인 게임은 오프라인에서도 실행할 수 있습니다.

이 앱은 학습·놀이용 가상 시뮬레이터이며 실제 사업이나 투자 조언이 아닙니다.
