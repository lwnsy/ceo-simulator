CEO SIMULATOR — 9개 업종 업데이트

이 패키지는 기존 ceo-simulator 저장소의 파일 구조에 맞춰 정리한 업데이트본입니다.

업종 9개:
1. 반도체·전자
2. 엔터테인먼트
3. 자동차·제조
4. IT·플랫폼
5. 유통·식품
6. 금융·보험
7. 에너지·환경
8. 바이오·헬스케어
9. 건설·부동산

포함 기능:
- 회사 이름과 CEO 이름 입력
- 업종별 시작 능력치와 경쟁 기업
- 쉬움/보통/어려움 난이도
- 경영 행동 후 이벤트 선택과 결과 반영
- 직원 직접 이름 설정, 역할별 장단점과 급여, 채용/해고
- 기업 가치, 누적 매출, 기술력, 시장 점유율, 평판 랭킹
- 장기 경영, 자동 저장, 월별 경영 기록
- 모바일 반응형 화면 및 PWA 설정

GitHub Pages 적용 방법:
1. 압축을 풀고 ceo-simulator-main 폴더를 엽니다.
2. 폴더 안의 파일과 icons 폴더를 GitHub 저장소의 첫 화면(root)에 업로드합니다.
   ceo-simulator-main 폴더 자체를 한 단계 더 안쪽에 업로드하지 마세요.
3. 기존 index.html, manifest.json, sw.js와 같은 경로의 아이콘 파일은 새 파일로 교체합니다.
4. main 브랜치에 커밋한 뒤 Pages 배포가 끝날 때까지 기다립니다.
5. 사이트를 열고 Ctrl+F5로 새로고침합니다. 기존 캐시가 남으면 잠시 기다렸다 다시 확인합니다.

진행 상황은 이 기기의 브라우저 localStorage에 자동 저장됩니다. 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다.
현재 랭킹은 게임 안의 가상 경쟁사와 비교하는 시스템이며, 온라인 실시간 순위는 아닙니다.
